# actions

Shared GitHub Actions.

| Action | Description |
| --- | --- |
| [invisible-ai-injection-guard](invisible-ai-injection-guard/README.md) | Flags issues, pull requests and comments that contain content hidden from people but visible to AI agents. |
| [verify-commit-signatures](verify-commit-signatures/README.md) | Fails a pull request that contains commits without a GitHub-verified signature. |
