# actions

Shared GitHub Actions.

| Action | Description |
| --- | --- |
| [close-on-labels](close-on-labels/README.md) | Closes an issue or pull request when its labels match an ordered list of rules. |
| [verify-commit-signatures](verify-commit-signatures/README.md) | Fails a pull request that contains commits without a GitHub-verified signature. |

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for the rules every action follows. Agents should start from [AGENTS.md](AGENTS.md).
